# Clínica Pediátrica con Farmacia Integrada

Sistema web para una clínica pediátrica con farmacia integrada.

- **Lenguaje:** PHP
- **Framework:** Laravel
- **Base de datos:** PostgreSQL
- **Metodología:** Scrum (sprints de 1 día) + prácticas XP
- **Arquitectura:** Monolito modular por capas (MVC + Services + Repositories)

Curso: Prueba y Calidad de Software
